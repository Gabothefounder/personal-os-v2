# Wisdom library

DEEP LIBRARY ≠ ACTIVE CONTEXT

`people/` and `books/` may hold extensive source notes.

`lenses/` are short, decision-oriented extracts. A decision should normally use **3–5 relevant lenses**, never the whole library.

Do not load this library by default. Route through `wisdom/syntheses/OPPORTUNITY_ENGINE.md`.

| Path | Role |
|---|---|
| `people/` | Source notes on thinkers |
| `books/` | Source notes on books |
| `lenses/` | Derived principles for decisions |
| `syntheses/` | How to select and apply lenses |

Source material is distinct from derived principles. Do not treat an empty person/book file as a populated lens.
